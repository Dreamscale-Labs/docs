Each model is trained for one robot type: build its observations with that robot's
helper. Frames are H×W×3 `uint8` RGB of any size.

[the steps your robot ran](/reference/sdk#history-the-model-reads).
`dreamscale models list` shows yours.
The previous ids `pi05-libero`, `pi05-so101` and `pi05-yam` are aliases.

## SO-101

```python
observation = dreamscale.so101.observation(
    side_frame=side,
    wrist_frame=wrist,
    joint_positions=joints,  # 6 values
)
```

- Joint order: `shoulder_pan`, `shoulder_lift`, `elbow_flex`, `wrist_flex`,
  `wrist_roll`, `gripper`.
- Joints are in calibrated LeRobot degrees; the gripper is 0–100.
- Actions are absolute targets in the same order and units.

## Bimanual YAM

```python
observation = dreamscale.yam.observation(
    top_frame=top,
    left_frame=left_wrist,
    right_frame=right_wrist,
    left_joint_positions=left_joints,    # 6 values, radians
    left_gripper=left_gripper,           # 0 closed to 1 open
    right_joint_positions=right_joints,  # 6 values, radians
    right_gripper=right_gripper,         # 0 closed to 1 open
)
```

- Actions are 14 absolute targets: left joints 1–6, left gripper, right joints
  1–6, right gripper.
- Grippers are continuous: don't threshold them.

## LIBERO

```python
observation = dreamscale.libero.observation(
    agent_frame=agent_view,  # agentview_image
    wrist_frame=wrist_view,  # robot0_eye_in_hand_image
    state=state,             # 8 values
)
```

- State: end-effector position (3), rotation as an axis-angle
  vector (3), then the two gripper joint positions.
- Pass frames as LIBERO renders them: the SDK flips them.
- Actions are LIBERO deltas: `dx`, `dy`, `dz`, three axis-angle rotation
  deltas, then the gripper (−1 open, +1 close).
- `long-wam-libero` runs in `dreamscale sim libero` only.
