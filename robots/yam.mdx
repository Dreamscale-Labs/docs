## What you need

- Two I2RT YAM arms with grippers, each on its own CAN adapter.
- Three RGB cameras: **top**, **left wrist** and **right wrist**. USB (UVC),
  ZED and RealSense cameras work.
- A Linux computer wired to the arms and cameras.
- A hardware e-stop within reach.

## 1. Install on the robot computer

On Debian or Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y iproute2 libusb-1.0-0 libgl1 libglib2.0-0
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install dreamscale
dreamscale login
```

`dreamscale login` prints `✓ saved login to ...`. Then bring both CAN
interfaces up at 1 Mbit/s. To keep their names stable across reboots, follow
I2RT's [persistent CAN naming guide](https://github.com/i2rt-robotics/i2rt/blob/120c3c81400171174604e503943f8d1ebc891058/docs/guides/set-persistent-can-ids.md).

## 2. Set up the rig

```bash
dreamscale robots yam setup
```

Open the URL it prints from any computer on the same network, then:

1. Preview each camera and assign it to top, left or right.
2. Pick each arm's CAN adapter, arm variant and gripper variant.

Setup does not move the arms. It saves your rig to `~/.config/dreamscale/yam.json`.
No browser? Use `dreamscale robots yam setup --cli`.

## 3. Check everything

```bash
dreamscale doctor yam
```

It prints the model `run` will use, then checks the cameras, CAN buses and
your access to that model without moving the arms. Every line shows a `✓`.

## 4. Run a model

<Warning>
  Both arms will move. Clear the workspace and keep the e-stop
  within reach. Software limits do not prevent collisions, and cloud inference
  does not replace your robot's safety limits.
</Warning>

```bash
dreamscale run yam
```

It prints `Using molmoact2-bimanual-yam (pass --model to choose)`, then:

1. At `Enter to start`, press **Enter** to connect. Both arms power on and
   calibrate their grippers.
2. At `Instruction`, type a task, for example `fold the towel`.
3. The arms show a preview of the first actions. Nothing moves yet.
4. Press **Enter** to run. Press **Ctrl+C** to stop.
5. The arms return home and ask for the next instruction. Press **Ctrl+C**
   again to exit.

The arms keep holding their pose after the command exits. This is powered
holding, not a brake. Support the arms, then release the motors:

```bash
dreamscale robots yam release
```

## Models

Choose one with `--model`, for example `dreamscale run yam --model pi05-yam`:

- `molmoact2-bimanual-yam`: MolmoAct2.
- `pi05-yam`: π0.5.

`dreamscale models` shows which ones your organization can run right now.
Stuck? See [Troubleshooting](/troubleshooting).
