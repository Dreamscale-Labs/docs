Allow about 20 minutes.

## What you need

- An SO-101 follower arm, connected by USB.
- Two USB cameras: a **side** camera on a fixed mount and a **wrist** camera on
  the arm.
- A computer or Raspberry Pi 5.
- The Dreamscale CLI, signed in. See [Quick start](/).

## 1. Place the cameras

Put the side camera 60–80 cm from the arm, side-on, with the whole arm and
workspace in frame. Use even lighting and a plain background.

Mount the wrist camera so it sees the gripper. Route its cable so no joint can
pull it.

## 2. Set up the arm and cameras

```bash
dreamscale robots so101 setup
```

Select the detected arm port and the side and wrist cameras.

## 3. Calibrate

```bash
dreamscale robots so101 calibrate
```

Clear the table and follow the prompts to move each joint through its range.

## 4. Check everything

```bash
dreamscale doctor so101 --model molmoact2-so101
```

It checks the port, calibration, both cameras and your access to that model,
and shows your side camera next to the reference framing. Every line shows a `✓`.

## 5. Run a model

<Warning>
  The arm will move. Clear the workspace, keep people and cables
  out of reach, and keep the power switch within reach. Cloud inference does
  not replace your robot's safety limits.
</Warning>

```bash
dreamscale run so101 --model molmoact2-so101
```

`--model` is required; [Models](#models) lists the others. Then:

1. Enter a task, such as `pick up the red block and put it in the box`.
2. Read the motion warning; press **Enter** to connect the arm.
3. The CLI shows the first prediction, then executes with current observations.
4. Press **Ctrl+C** to stop and return home; press it again to exit.

The arm keeps holding after exit. Support it before releasing the motors:

```bash
dreamscale robots so101 release
```

## Models

Choose with `--model`:

- `molmoact2-so101`: MolmoAct2.
- `flux-3-action-so101`: FLUX 3 Action.
- `pi0.5-so101`: π0.5.
- `praxis-1-so101`: Praxis-1, using the default sync mode at 15 Hz.

`dreamscale models list` shows which you can run.
Stuck? See [Troubleshooting](/troubleshooting).
