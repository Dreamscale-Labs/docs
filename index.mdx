Dreamscale runs robot models on cloud GPUs. Your robot sends camera frames and
joint positions, and gets back actions in real time.

## Try it in your browser

Sign in to the [dashboard](https://app.dreamscalelabs.com/dashboard), then open
[Sim](https://app.dreamscalelabs.com/dashboard/sim). A MolmoAct2 model drives a
simulated arm through a LIBERO task. Nothing to install.

## Choose your path

- **CLI**: one command runs a model on a supported robot or in the simulator.
  `uv tool install dreamscale`.
- **Python SDK**: full control. Call models from your own robot, loop or pipeline.
  `uv add dreamscale`. Start at [Python SDK](/python).

Both install the same `dreamscale` package. The rest of this page is the CLI.

## Run the simulator from the CLI

1. Install the CLI. It works on macOS, Linux and Windows (WSL2).

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   uv tool install dreamscale
   ```

   `dreamscale --version` prints `{{sdkVersion}}` or newer.

2. Sign in or create an account in your browser.

   ```bash
   dreamscale login
   ```

   It prints `✓ saved login to ...` when you are signed in.

3. Run a model in the LIBERO simulator.

   ```bash
   dreamscale sim libero
   ```

   The first run downloads the simulator (several GB on Linux), which can take a
   few minutes. A server connects in seconds, longer if all are busy.
   It prints `Using pi0.5-libero (pass --model to choose)`, a window
   opens and the model drives the arm. The run ends with
   `result: success condition reached`.

Already have the CLI? Update it with `uv tool upgrade dreamscale`.
