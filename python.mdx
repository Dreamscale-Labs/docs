The Python SDK gives you full control: your own robot, cameras, control loop and
pipeline. Just want to run a model on an SO-101 or bimanual YAM? The CLI does it
with one command: see [SO-101](/robots/so101) or [Bimanual YAM](/robots/yam).

## What you need

- Python 3.11 or newer, in a project (`uv init` makes one).
- A Dreamscale account. Sign in once with `uv run dreamscale login`, or set
  `DREAMSCALE_API_KEY` to a key from
  [Settings → API keys](https://app.dreamscalelabs.com/dashboard/settings#api-keys).

## Install

```bash
uv add dreamscale
```

`uv run python -c "import dreamscale; print(dreamscale.__version__)"` prints
`{{sdkVersion}}` or newer.

## Get one action chunk

This runs as-is. It sends blank frames and a zero state to `pi0.5-libero`, the
π0.5 model for the LIBERO simulator:

```python
import numpy as np

import dreamscale

policy = dreamscale.connect("pi0.5-libero")
frame = np.zeros((256, 256, 3), dtype=np.uint8)  # H×W×3 uint8 RGB
observation = dreamscale.libero.observe(
    agent_frame=frame,
    wrist_frame=frame,
    state=[0.0] * 8,
)
chunk = policy.predict(observation, instruction="pick up the black bowl")
print(len(chunk.actions), "x", len(chunk.actions[0]))
```

It prints `20 x 7`: 20 actions of 7 values. `connect` returns when a GPU is
ready; if every GPU is busy, it waits in a queue and shows your position. Now
replace the frames and state with your own. See [Models](/models) for each
robot's observation and actions.

## Drive a robot

<Warning>
  The robot will move. Enforce joint, speed and workspace limits locally, and
  keep a physical e-stop within reach. Cloud inference does not replace your
  robot's safety controller.
</Warning>

Call `next_action` once per control tick. It returns one action on the model's
clock, so the loop needs no timing code. This loop drives an SO-101; pick a
model for your robot from `uv run dreamscale models`.

```python
import dreamscale

policy = dreamscale.connect("flux-3-action-so101")

def read_observation():
    # Your code: read the side and wrist cameras and the 6 joint positions.
    return dreamscale.so101.observe(side_frame=side, wrist_frame=wrist, joint_positions=joints)

def send_to_robot(action):

    ...

while True:
    send_to_robot(policy.next_action(read_observation(), instruction="pick up the red block"))
```

Pass a new instruction at any time to switch tasks.

## What the SDK handles

The SDK checks each observation before sending it and names the field that is
wrong. It prepares images, streams to the GPU over the fastest path your network
allows, and blends chunks so motion stays smooth. It spaces requests at least
0.4 s apart. If the connection drops, it
reconnects and holds the robot still until actions arrive. It releases the GPU
after a minute without calls and reconnects on the next one. Sessions close
when your program exits, or call `policy.close()`. In async code, use
`await dreamscale.aconnect(...)`.
