This is Dreamscale's turnkey hardware path. It configures one SO-101 follower arm,
a side camera, and a distinct wrist camera, then previews each prediction
without motion. The arm moves only after the operator reviews the preview and
explicitly confirms the task.

<Warning>
  Keep the robot inside a clear workspace with a reachable physical power stop.
  Stay close enough to stop it, but keep people, cables, and loose objects
  outside its swept volume. A keyboard stop supplements the physical stop; it
  does not replace it.
</Warning>

## Requirements

- Python 3.12 or 3.13;
- an SO-101 follower arm supported by LeRobot 0.5.1;
- one side RGB camera and one distinct wrist RGB camera;
- a terminal attached to a TTY for the keyboard e-stop;
- a Dreamscale account with available credits.

## 1. Install and authenticate

```bash
uv tool install "dreamscale[so101]"
dreamscale login
dreamscale doctor
```

`dreamscale login` initializes motion as disabled on a new machine.

## 2. Prepare the workspace

Before connecting:

1. Secure the arm base and both cameras.
2. Route the wrist-camera cable so no joint can pull or trap it.
3. Remove tools and unused props from the swept volume.
4. Test the robot's physical power stop.
5. Place the terminal where `Ctrl-C` is immediately reachable.

### Side camera

Mount the side camera 60–80 cm from the table, approximately side-on to the
arm, with the whole workspace and arm visible. Keep exposure, white balance,
and the mount stable during a run.

### Wrist camera

Use a second physical camera mounted on the arm. Keep the gripper and immediate
workspace visible, secure the cable through the full joint range, and verify
that it is not the same device index as the side camera.

## 3. Detect the arm and cameras

```bash
dreamscale robots so101 setup
```

The setup flow:

1. verifies your API key;
2. detects or confirms the serial port;
3. previews and saves the side camera;
4. previews and saves a distinct wrist camera;
5. starts warming the SO-101 policy worker while you finish setup.

Configuration is written to `~/.dreamscale/config.toml`. If setup starts a cloud
session and you stop here, close it with:

```bash
dreamscale sessions list
dreamscale sessions stop <session-id>
```

## 4. Calibrate

Clear the table, then run the guided LeRobot calibration:

```bash
dreamscale robots so101 calibrate
```

Follow the prompts to place the arm near the middle of its range and sweep each
joint. Dreamscale writes the LeRobot 3.0 calibration format to
`~/.dreamscale/calibration/so101.json`.

Do not continue if the calibration exits early or the saved joint ranges look
wrong. Re-run calibration with the workspace clear.

## 5. Pass hardware diagnostics

```bash
dreamscale doctor so101
```

The command checks:

- Python and LeRobot versions;
- the configured serial port;
- calibration presence and format;
- distinct side and wrist camera capture;
- side-camera framing against the reference;
- the current network path when a warmed session is available.

The command ends with a `✓` verdict line when every check passes.

Fix every failure and re-run the command. A skipped network preflight is
acceptable when no warm session exists; connection performs the check again.

## 6. Preview one prediction without motion

Stage a red block and target square, keep the workspace clear, and run:

```bash
dreamscale run so101 --model molmoact2-so101
```

The command asks you to press Enter to start, connects the arm, and asks for an
instruction. For each instruction, it moves the arm to its saved home pose (if
you saved one), then requests one prediction and dispatches none of it:

```text
Prediction only: ... actions; none dispatched.
Largest requested joint change from current pose: ...
```

Inspect the preview for:

- six finite values in the documented joint order;
- plausible targets near the current pose;
- stable camera framing;
- no unexpected discontinuities.

Press `Ctrl-C` to cancel if the stop path, cameras, calibration, or targets
are wrong.

## 7. Confirm one live run

After the preview, the command asks:

```text
Press Enter to execute until stopped, or Ctrl+C to cancel:
```

Before pressing Enter, confirm again that:

- the physical stop works and is reachable;
- one operator is watching the entire workspace;
- no person or object is inside the swept volume;
- calibration and diagnostics passed in this setup;
- the previewed targets were plausible.

Press Enter only when all checks pass. Every task previews first and asks
again; nothing is remembered between runs. The loop caps each per-tick joint
change (`--max-joint-step`) and joint speed (`--max-joint-velocity`). Press
`Ctrl-C` to stop the task: the arm holds, returns to its saved home pose (if
any), and the command asks for the next instruction. Press `Ctrl-C` at the instruction prompt to disconnect.
Add `--max-actions` to limit each task.

<Warning>
  The arm holds its pose when the command exits. Physically support the arm,
  then run `dreamscale robots so101 release` to release motor torque.
</Warning>

## Stop and recover

- Press `Ctrl-C` to stop the task in software.
- Use the physical power stop for unexpected motion or any loss of confidence.
- After a disconnect or timeout, leave the arm stopped, inspect
  `dreamscale sessions list`, and run `dreamscale doctor so101` before retrying.
- If UDP is unavailable, the command may use the hosted relay and will report
  reduced responsiveness.
- If a session remains open, terminate it with
  `dreamscale sessions stop <session-id>`.
