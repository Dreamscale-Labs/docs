No robot or GPU needed. The current release is `{{sdkVersion}}`.

<Tip>
  Just want to look? Open the [browser simulator](https://app.dreamscalelabs.com/dashboard/sim)
  in the dashboard. Nothing to install.
</Tip>

## 1. Install

```bash
uv tool install dreamscale
```

No `uv` yet? Install it with `curl -LsSf https://astral.sh/uv/install.sh | sh`,
or use `pip install dreamscale`. Dreamscale supports macOS, Linux, and Windows
(WSL2) with Python 3.11–3.14.

## 2. Sign in

```bash
dreamscale login
```

This opens your browser. Create an account or sign in, then approve the
machine.

<Check>
  `dreamscale doctor` shows a green check for every core item.
</Check>

## 3. Run a model in simulation

```bash
dreamscale sim libero --model molmoact2-libero --task-suite libero_spatial --task-id 0
```

The first run installs simulator support and downloads the LIBERO scenes, which
takes a minute or two. Then a window opens and the model drives a simulated arm
through the task.

<Check>
  The run ends with `result: success condition reached`.
</Check>

<Note>
  After a run, the GPU stays reserved for 5 minutes so your next run starts
  instantly. Reserved time is billed. Add `--keep-warm 0` to release it right
  away.
</Note>
